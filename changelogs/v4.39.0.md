## What's new in upstream PebbleOS v4.39.0

309 upstream commits since v4.38.0, summarized by Claude from the commit messages. Upstream release: https://github.com/coredevices/PebbleOS/releases/tag/v4.39.0

**Notifications**
- Notification history can group messages by sender, opening each sender as a newest-first transcript. A new Settings option sets the grouping range (never, one day, one week or all history).
- Notifications you already acted on or dismissed no longer come back in the Notifications app or the launcher glance.
- Fixed notifications that popped away instantly without vibrating when the phone app's timeout slider was set to 0; the watch now enforces a 15 s minimum.
- Emoji replies show as a large glyph grid (three scrolling columns at twice the old size on Pebble Time 2).

**Emoji and text**
- Color emoji fonts: hundreds of emoji redrawn in Pebble style and rendered in color on color displays.
- The Watchfaces list now follows the Text Size setting like the other system menus.

**Battery / Power**
- An idle watch wakes far less often: the minute tick no longer fires every second, idle system threads are no longer woken every second, and clock calibration shares the minute wake-up.
- Bluetooth idle connection events are halved (relaxed slave latency raised to 30), measured on Pebble Time 2.

**Pebble Time 2 (obelix)**
- Fixed a touch panel false-trigger on some units that could keep the backlight on indefinitely.
- Accelerometer data is now read through DMA.
- Vibration motor (AW8623X) braking corrected, with recovery when a stop fails.

**Health**
- New 5-minute background heart rate interval in Settings, Health.
- Workouts reject low-quality heart rate samples, and starting a workout ends any ongoing activity session.

**Apps / UI**
- New Quick Launch action to toggle the touchscreen.
- Long status bar titles scroll instead of being clipped on round displays.

**Bluetooth / Reliability**
- Fixed "delete all pairings" corrupting other stored entries and possibly deadlocking storage.
- Stack overflows are detected and reported more reliably; system apps get a 4 KiB stack.
- Memory fixes in heap_realloc(), safe_strcat() and the shared circular buffer, plus a use-after-free in get_bytes.

**Build / CI / Docs**
- Source tree moved from src/fw to fw, a new integration-test harness runs on the emulator, the SDK moved to 0.1.10, and much of the public API is now documented.

...and about 200 more internal, refactoring and documentation commits.
