## What's new in upstream PebbleOS v4.41.1

3 upstream commits since v4.41.0, summarized by Claude from the commit messages. Upstream release: https://github.com/coredevices/PebbleOS/releases/tag/v4.41.1

- Fixed a crash that could happen after a background worker (such as a watchface's companion app) failed to launch.
- Fixed background worker memory sizing so a worker that needs more memory is caught at build time instead of silently failing to launch.
- Fixed a memory layout issue that could stop background workers from launching and crash the watch when it tried to close them.
