## What's new in upstream PebbleOS v4.9.142.7

3 upstream commits since v4.9.142.6, summarized by Claude from the commit messages. Upstream release: https://github.com/coredevices/PebbleOS/releases/tag/v4.9.142.7

This is a fix release for the older v4.9.142 firmware line, not an update for a watch already running newer firmware.

- Manufacturing charge test now fails and reports the reason when the charger reports an error or the charge phase runs past 1.5 hours, instead of staying stuck showing "Charging" forever.
- Battery status now reports a distinct error state when the charger reports a fault, so it is no longer mistaken for an unknown idle state.
- The charger driver now detects and reports hardware charging faults such as sensor errors, low battery voltage, and measurement or timeout issues.
