## What's new in upstream PebbleOS v4.41.0

216 upstream commits since v4.40.0, summarized by Claude from the commit messages. Upstream release: https://github.com/coredevices/PebbleOS/releases/tag/v4.41.0

**Notifications**
- Added a "Notifications" toggle under Quiet Time backlight settings, so phone calls and other alerts can light the screen during Quiet Time independently of vibration.
- Pings from the phone no longer stack up a dialog for every single ping; a quick burst of pings could previously pile up enough dialogs to run the watch out of memory and crash it.
- Fixed a crash that could happen if the phone cleared your notifications while one was still popping up on screen.

**Bluetooth**
- The watch now properly refuses new pairing requests from other phones while it isn't meant to be discoverable, closing a gap where an unexpected phone could still try to pair with it.
- Fixed a hang where a failed Bluetooth service discovery could block every connection afterward, eventually requiring a restart.
- Fixed several crashes and hangs that could occur when Bluetooth was stopped (entering airplane mode, or during a reset) while a connection, discovery, or pairing was still in progress.
- Forgetting a paired phone now fully stops the old reconnection advertising and clears its Bluetooth keys, instead of leaving the watch stuck alternating between two advertising states until a reboot.
- Fixed the advertised Bluetooth signal strength showing garbage values instead of the real number.

**Health**
- Fixed a crash in the heart rate sensor that could happen when its data feed was turned off and back on in quick succession.
- Fixed bugs where changing an app's accelerometer batch size, or unsubscribing from accelerometer data, could corrupt readings, silently stop data from arriving, or crash the requesting app.

**Timeline**
- Weather pins now keep their city name clear of the page-turn arrow on shorter displays.
- Tightened the spacing between the time and title on extra-large text size pins.
- Round-display event titles are now centered consistently across all text sizes.

**Phone**
- Fixed the call screen layout on larger round displays so the caller's name is positioned correctly.

**Music**
- Track position and length now display correctly for tracks 100 hours or longer, instead of a cut-off time.

**Alarms**
- Fixed a bug where editing an alarm's time, type, or repeat schedule didn't cancel an already-set snooze.

**Apps / UI**
- Corrected menu row spacing on affected boards so padding matches the intended design.

**Drivers / Reliability**
- Fixed a bug that could hang the watch and force a watchdog reset while the phone was setting the time.
- Fixed a flash memory bug that could hang the watch and force a watchdog reset under heavy use, such as many Bluetooth pairings in a row.

**Build / Internal**
- Migrated the firmware's C code to the newer C23 language standard, updated the build toolchain and SDK (also trimming several kilobytes off firmware size), and overhauled compiler warnings, internal data layouts, and the automated test and CI infrastructure. ...and about 190 more internal commits.
