## What's new in upstream PebbleOS v4.9.142.11

2 upstream commits since v4.9.142.10, summarized by Claude from the commit messages. Upstream release: https://github.com/coredevices/PebbleOS/releases/tag/v4.9.142.11

This is a fix release for the older v4.9.142 firmware line, not an update for a watch running newer firmware.

- Reboot log entries are now correctly labeled for every reason, so entering PRF through the button combo or Extras, Load PRF no longer shows up as an unrecognized reset.
- Fixed a logging bug where the reboot reason message only printed Safely or Dangerously instead of the actual reason, making diagnosing restarts more reliable.
